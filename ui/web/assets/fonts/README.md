# Fonts

`zpix.ttf` is **Zpix (最像素)** v3.1.9 by SolidZORO, from
https://github.com/SolidZORO/zpix-pixel-font. The café uses it for Chinese (and Japanese) text,
through an `@font-face` with a CJK `unicode-range`, so browsers download it only when such text is on
screen.

License, per the author: free for education and personal projects; a commercial product needs a
paid license from the author. The font may not be modified, decompiled, converted or split, so it is
kept here exactly as released (no subsetting, no WOFF2). PhiloCafe is a course project; if it ever
becomes a commercial product, buy a license or switch fonts first.
